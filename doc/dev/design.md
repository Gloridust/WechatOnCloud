# 设计规范 · 云微面板设计系统（牛奶布艺 2.0）

> 本文是面板前端（`panel/web`）的设计语言与组件规范，和代码一一对应：令牌就是 `styles.css` 里的 CSS 变量，组件名就是真实的 class 或 `ui.tsx` 里的 React 组件。改 UI 前先读这里，新增组件按这里落地，别另起炉灶。
> 配套：架构层规范见 [架构守则.md](架构守则.md)。

## 一、设计哲学

整个界面是盖在桌面上的一整块柔软白布，每个组件都是被布从下面顶起的物体。这个比喻决定了几乎所有视觉选择：高光落在物体顶面（中心偏上的 radial 渐变），阴影是紧贴边缘的布料折痕而不是悬浮投影，组件永远比布底亮，层级靠明度区分而不靠描边。输入框、进度槽、分段选择器的底则反过来，是按进布里的槽，用更暗的底色加内阴影。真正「浮」在布上方的东西只有两类：下拉菜单和弹窗，只有它们可以用大投影 `--float`。

主色是微信绿 `#07C160`。用户对这个绿有肌肉记忆，色相不改。2.0 把绿色的用法收紧了：实心绿只给需要用户动手的动作，比如待安装实例的「下载安装微信」、已停止实例的「启动」、可升级时的「一键升级」、弹窗里的「保存」；一切正常时的常用入口（在线实例的「进入实例」）用柔和的浅绿按钮 `.btn-soft`，这样一屏卡片里哪张需要处理一眼就能挑出来。白底上的绿字统一用压暗的 `--accent-text`（`#067f3f`，对比度约 5:1），`#07C160` 做文字只有 2.4:1，读不清。

2.0 相对 1.x 的调整：折痕更轻（此前每张卡都像一块厚砖），加了正文用的二级灰 `--text-2`，统一了字号、间距、圆角和控件高度的档位，引入一套线性图标（`icons.tsx`，lucide 风格），补上语义色（成功、注意、危险、信息）。检验标准还是那一句：任何新组件放上去，要像同一块布下顶起的又一个物体，而不是贴上去的一张卡。

## 二、设计令牌

改样式只用令牌，不写死颜色、阴影和圆角。浅色在 `:root`，深色在 `:root[data-theme='dark']`，跟随系统时由 `@media (prefers-color-scheme: dark)` 里的 `[data-theme='auto']` 套用同一组值。

### 色彩

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--base` | `#edeff3` | `#121419` | 布底（页面背景） |
| `--surface` | `#ffffff` | `#1e2129` | 顶起的表面：卡片、按钮、面板 |
| `--surface-2` | `#f5f6f8` | `#262a33` | 表面上的次级区块：卡内分组、悬停行、勾选列表底 |
| `--surface-float` | `#ffffff` | `#262a34` | 下拉菜单、Toast。深色下比卡片亮一档，叠在卡片上才分得清 |
| `--trough` | `#e6e9ee` | `#0d0f13` | 凹槽：输入框、进度槽、分段选择器底 |
| `--line` | 阴影色 10% | 白 7% | 极少数必须分隔的列表行、弹窗页脚 |
| `--text` | `#1b1e25` | `#e8eaef` | 主文字 |
| `--text-2` | `#4b5260` | `#b6bcc6` | 正文说明、次要按钮文字 |
| `--muted` | `#8a919c` | `#878e99` | 辅助信息，最浅只到这一级 |
| `--wx-green` / `--wx-green-dark` | `#07c160` / `#06ad56` | 同 | 主按钮底、选中态、状态点 / 按下态 |
| `--accent-text` | `#067f3f` | `#3ad386` | 绿色文字：链接、选中项文字、柔和按钮 |
| `--danger` / `--danger-text` | `#f04848` / `#d33232` | 同 / `#ff7a7a` | 危险底色 / 危险文字 |
| `--warn` / `--warn-text` | `#f2a32a` / `#9c5d00` | 同 / `#f5b95c` | 注意（待安装、可升级） |
| `--info` / `--info-text` | `#3b82f6` / `#2563c4` | 同 / `#7fb0ff` | 信息（安装中、只读提示） |
| `--off` | `#b9bfc9` | `#5d6470` | 停止、未创建 |
| `--shadow` | `46 58 89` | `0 0 0` | 阴影色 RGB，配 `rgb(var(--shadow) / α)` |
| `--green-rgb` / `--danger-rgb` / `--warn-rgb` / `--info-rgb` | — | — | 各语义色的 RGB，做半透明底（tag、callout） |

深色不是简单反色：布底是亮一点的蓝黑，表面再高一档，阴影换成近纯黑，顶面高光压到几乎看不见；浮层在深色下额外带一圈 1px 的白色细边（写在 `--float` 里），否则菜单和下面的卡片糊成一片。

### 尺寸档位

| 令牌 | 值 | 用途 |
|---|---|---|
| `--r-xl` | 24px | 卡片、弹窗、浮动面板 |
| `--r-lg` | 18px | 面板、大块选项、下拉菜单 |
| `--r-md` | 14px | 按钮、输入框 |
| `--r-sm` | 10px | 小按钮、图标按钮、菜单项 |
| 胶囊 | 999px | 徽标 `.tag`、分段选择器、状态点 |
| `--h-sm` / `--h-md` / `--h-lg` | 34 / 42 / 48px | 小按钮 / 常规按钮与输入框 / 登录等大按钮 |

旧名 `--r-card`、`--r-blob`、`--r-small` 还留着做兼容，分别等于 xl、lg、md，新代码别再用。字号有四档常用值：页面大标题 24、卡片和弹窗标题 17–19、正文 14–15、辅助 12.5–13.5；正文行高 1.5，说明文字 1.6。

### 阴影与高光

| 令牌 | 含义 |
|---|---|
| `--crease` | 顶起的折痕，两层都紧贴边缘（`0 1px 2px` + `0 2px 8px`）。所有顶起组件的基础 |
| `--crease-hover` / `--crease-press` | 悬停略深 / 按下收紧，模拟按进布里 |
| `--crease-accent` / `--crease-danger` | 主按钮、危险按钮的彩色折痕 |
| `--float` | 只给下拉菜单、弹窗、Toast、桌面页的浮动面板 |
| `--inset` | 凹槽的内阴影 |
| `--sheen` | 顶面高光，所有顶起组件用 `::before` 叠这一层，否则会变成平贴的色块 |
| `--focus` | 输入框聚焦的绿色光环 |

折痕的硬约束是 x 恒为 0、y 不超过 6、第一层模糊不超过 4、第二层不超过 14。模糊大了、y 大了，就成了悬浮投影，违反比喻。

### 动效

主曲线是 `--ease`（`cubic-bezier(0.2, 0.8, 0.2, 1)`），时长 0.14–0.2s，按钮、菜单、弹窗、Tab 都用它。按下反馈是 `scale(0.97)`（图标按钮 0.94）加折痕收紧。悬停效果一律写在 `@media (hover: hover)` 里，触屏上不会出现点完之后一直「悬停」的残影。`prefers-reduced-motion: reduce` 时去掉装饰性的过渡和位移，但保留转圈和不确定进度条的循环，不然看起来像卡死。

## 三、布局与信息架构

外壳是左侧栏加右侧工作区。侧栏放主页、实例列表（带状态点，非在线状态才写字）、管理和退出；宽屏可以收起成图标栏，手机上变成抽屉。工作区顶部是 56px 的标题栏（`.ws-head`），左边是页面或实例名，右边是这一页的工具。内容区 `.ws-page .content` 本身就是滚动容器，铺满整宽，滚动条贴着窗口右边，内容靠左右内边距收成 1060px 居中；`scrollbar-gutter: stable` 保证切 Tab 时页面不会因为滚动条出现或消失而左右跳。

管理页按使用频率分成三个 Tab：实例（日常）、账号（偶尔配置）、系统（出事才看：待清理的残留、诊断、关于）。Tab 上的红点 `.seg-dot` 提示「这里有事要处理」，免得藏进 Tab 的事被漏看。当前 Tab 的主操作放在 Tab 行右侧，手机上缩成圆形的「+」。

实例卡片的网格是 `repeat(auto-fill, minmax(290px, 1fr))`，`align-items: start`，各卡按自身内容高度排列：同一行有一张卡显示长报错时，不把其它卡也拉高。

## 四、组件

### 共用原子
`.card`、`.inst-card`、`.home-card`、`.panel`、`.list-card` 共享同一套顶起样式：`--surface` 底、`--crease` 折痕、`::before` 叠 `--sheen`、圆角 `--r-xl`。新的顶起容器加进这组选择器，别各写一份。

### 按钮
| 类 | 形态 | 用途 |
|---|---|---|
| `.btn` | 白底顶起 | 次要动作（取消、上传壁纸） |
| `.btn.btn-primary` | 实心绿，彩色折痕 | 需要动手的动作；同一张卡、同一个弹窗里最多一个 |
| `.btn.btn-soft` | 浅绿底、绿字、不顶起 | 正常状态下的常用动作，比如在线实例的「进入实例」 |
| `.btn.btn-danger` | 实心红 | 删除等破坏性动作，只出现在确认弹窗里 |
| `.btn.btn-ghost` | 透明 | 工具条上的轻动作（数据卷的上传、新建文件夹） |
| `.btn-text` | 无底、绿字，`.danger` 变红 | 行内轻操作（查看日志、恢复默认） |
| `.icon-btn` | 36px 方形透明，`.raised` 变成顶起小方块 | 工具栏、卡片的「⋯」、弹窗关闭 |

尺寸修饰 `.btn-sm`（34）、`.btn-lg`（48）、`.btn-block`（占满一行）。禁用态统一降到 50% 透明度，不改阴影。按钮里放图标时用 `<Icon size={16|17} />` 放在文字前面，忙碌时换成 `<Spinner size="sm" />`。

### 图标
统一用 `icons.tsx` 的 `<Icon name=… />`，2px 线宽、圆角端点，默认 18px。不要再在 JSX 里手写 SVG 路径，也不要用「✕」「⬇」「＋」这类字符当图标：字符的大小和基线随系统字体变化，安卓上会小到看不见或者渲染成方块。缺图标就往 `icons.tsx` 里加。

### 输入
`.input` 是凹槽：`--trough` 底加内阴影，聚焦时变回白底并亮起绿色光环，出错时 `.invalid` 换成红环。表单字段用 `<Field label hint error>` 包起来：标签在上，说明或错误在下；子元素是单个 input、select、textarea 或 `PasswordInput` 时，Field 会自动生成 id 把标签和控件关联上（点标签能聚焦，读屏能念出标签和说明），不用手写 `htmlFor`。密码一律用 `PasswordInput`，自带显示 / 隐藏切换。

### 徽标与状态
`.tag` 是带圆点的胶囊，变体对应语义色：`.tag-on` 在线（绿）、`.tag-busy` 安装中 / 处理中（蓝）、`.tag-warn` 待安装 / 可升级（橙）、`.tag-err` 安装出错（红）、`.tag-off` 已停止（灰）、`.tag-muted` 纯元数据。实例状态的颜色和文案由 `AppShell.tsx` 的 `statusOf()` 统一给出，侧栏角标、主页卡片、管理卡片、实例页标题处处同色同字，别在别处另写一套判断。

一个标题行最多放名字加一个状态徽标，其余信息（镜像版本、可访问的子账号、可升级）下沉到 `.ic-meta` 元数据行。

### 提示条
`.callout` 用来放需要读完的提醒，配左侧图标、标题、正文和右侧操作。`.callout-warn`（可升级）、`.callout-danger`（还在用默认密码、加载失败）、`.callout-ok`。它不是 Toast：Toast 说「刚才发生了什么」，提示条说「现在有件事要你处理」。

### 分段选择器
`.seg-tabs` 是凹槽胶囊，选中项 `.seg-tab.active` 是顶起的白胶囊，图标变绿。这套「凹槽加顶起」和输入框同构，是区分选中与未选中的标准范式；小一号的同类有 `.settings-tabs`（桌面设置的壁纸 / 字体）。

### 下拉菜单
`<MenuButton items>` 渲染到 body 上、fixed 定位，卡片有 `overflow: hidden` 也裁不到它，靠近屏幕底边时自动往上弹，支持方向键和 Esc。菜单项可以分组（`{ section }`）、加分隔线（`'sep'`）、标危险（`danger`），需要解释的选项给 `desc` 显示第二行说明，单选项给 `checked` 在右侧打勾（例如桌面页的中文输入方式）。操作超过两三个就收进菜单，卡片上只留一个主按钮。

### 弹窗
`<Modal title subtitle footer size onSubmit>` 渲染到 body，标题区带关闭按钮，内容区单独滚动，页脚固定在底部（取消在左、主动作在右）。尺寸 `sm`（380，确认框）、`md`（460，默认）、`lg`（720，数据卷管理）。多层弹窗时 Esc 只关最上面一层；在弹窗里按下鼠标拖到遮罩上松开不会误关。手机宽度下弹窗变成从底部滑出的面板。确认用 `useUI().confirm()`，别自己拼一个。

### Toast 与进度
`useUI().toast(text, kind)` 从底部中间弹出，带对应的图标；错误类停留更久。确定进度用 `.wx-progress-bar` 的宽度表示，不确定用 `.indeterminate` 循环。

### 空状态与加载
列表为空时用 `EmptyState`：图标、一句话说明、需要的话再给一个动作，别只写「暂无数据」。整块区域加载用 `<Spinner />`，有固定结构的面板加载用 `.skeleton` 占位，避免内容到了以后跳动。

### 实例桌面页
标题栏右侧是工具栏 `.ws-actions`：文件、剪贴板、中文输入方式、声音（开了才出现麦克风），最后是「⋯」更多（重新连接；管理员还有桌面设置、重启实例、查看日志）。宽屏显示图标加短标签，1180px 以下只留图标，手机上工具栏放不下时在自身范围内横向滑动。开关类（声音、麦克风）开着时是浅绿底，打开着的面板对应按钮是顶起的白底。

文件、剪贴板、桌面设置三个浮动面板 `.iv-files` 同一时间只开一个，Esc 关闭。实例不能直接进桌面时（已停止、未安装、安装中、安装失败）显示状态卡：应用图标右下角带一个状态角标，下面是一句说明和能直接点的操作。管理员在这里就能启动、安装、上传安装包、看日志，不用再跳回管理页；子账号看到的是该找谁处理。

## 五、无障碍

全局 `:focus-visible` 给 2px 绿色描边加 2px 偏移，只在键盘导航时出现，鼠标点击不触发；没有描边的拟物界面尤其需要它。文字最浅到 `--muted`，不用更浅的三级灰。交互目标至少 34px，手机上的主操作 42px 以上。纯图标按钮必须有 `aria-label`（`MenuButton` 用 `label`），开关类按钮带 `aria-pressed`，单选菜单项是 `menuitemradio`。

## 六、文案

全中文，语气像同事说人话，不像系统报错。出错时说清楚原因和下一步怎么办，而不只是「失败了」。按钮写动作本身（「下载安装微信」「接管操作」），不写「确定」。数字和版本号用 `tabular-nums`。破坏性操作在确认框里写明后果，按钮用红色并写出具体动作（「删除实例」而不是「确定」）。中文和英文、数字之间是否加空格以现有文案为准，同一处保持一致。

## 七、常见错误

| ❌ | ✅ |
|---|---|
| 大模糊、大 y 的投影 | 紧贴边缘的 `--crease` |
| 每张卡的主按钮都是实心绿 | 只给需要处理的状态用实心绿，正常进入用 `.btn-soft` |
| 用描边或分割线区分组件 | 靠明度（surface > base > trough）加折痕 |
| 写死 `#07c160` 或黑色阴影 | 用 `--wx-green`、`--accent-text`、`--crease` |
| 白底上用 `#07c160` 写字 | 用 `--accent-text` |
| 标题行塞名字加三个徽标 | 名字加一个状态徽标，其余进元数据行 |
| 卡片上平铺七八个按钮 | 一个主按钮，其余进 `MenuButton` 分组 |
| 「✕」「⬇」当图标 | `<Icon name="x" />`、`<Icon name="download" />` |
| 悬停效果直接写在选择器上 | 包在 `@media (hover: hover)` 里 |
| 深色下菜单和卡片同色 | 浮层用 `--surface-float` 加 `--float` |

## 八、落地清单

改或加 UI 之前过一遍：只用令牌；顶起组件有 surface 底、折痕和高光；实心绿只给需要动手的动作，同一张卡、同一个弹窗里最多一个；图标来自 `icons.tsx`；表单字段用 `Field`、弹窗用 `Modal`、菜单用 `MenuButton`；浅色和深色都看过（顶栏的主题开关）；390px 宽的手机上没有横向溢出、按钮点得到；键盘 Tab 能看到焦点环；破坏性操作有确认且按钮是红的。
